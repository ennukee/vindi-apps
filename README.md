# vindi-apps

Application review UI built with React + Vite.

## Local development

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

This project is configured to publish to:

`https://dbowers.io/vindi-apps`

Deployment command:

```bash
npm run deploy
```

Notes:

- `vite.config.js` uses `base: '/vindi-apps/'`.
- `npm run deploy` builds and publishes `dist` to the `gh-pages` branch.
